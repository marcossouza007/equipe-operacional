# Equipe Operacional - Sistema Multiagente de IA

Sistema corporativo multiagente em Python que simula uma empresa digital com especialistas IA em diversas áreas: Desenvolvimento, Ciência da Computação, Negócios, Redes, Segurança, Jurídico e Dados.

## 🏗️ Arquitetura

- **Frontend**: React
- **Backend**: FastAPI
- **Banco de Dados**: PostgreSQL
- **Vetorização**: Qdrant
- **Orquestração Multiagente**: LangGraph
- **IA Local**: Ollama
- **Modelos**: Llama, Mistral AI ou OpenAI

## 👥 Equipe de Agentes (17 Especialistas)

### Desenvolvimento de Software (5)
- Programador Backend
- Programador Frontend
- Programador Full Stack
- Engenheiro de Software Sênior
- Engenheiro DevOps

### Ciência da Computação (2)
- Cientista (Algoritmos)
- Cientista (Pesquisa)

### Negócios (2)
- Analista de Negócios
- Especialista em Processos

### Redes (2)
- Engenheiro de Redes Enterprise
- Engenheiro de Redes Telecom

### Segurança da Informação (2)
- Especialista em GRC
- Especialista em Cybersecurity

### Jurídico (1)
- Agente Jurídico

### Dados (3)
- Cientista de Dados (Machine Learning)
- Cientista de Dados (Analytics)
- Engenheiro de Dados

### Orquestração (1)
- **Agente Orquestrador Principal** (coordena todos)

## 📋 Módulos

1. **Módulo de Upload** - Aceita múltiplos formatos
2. **Módulo de Classificação** - Identifica tipo de arquivo automaticamente
3. **Módulo Multiagente** - Coordena especialistas
4. **Módulo de Memória** - Armazena histórico e conhecimento
5. **Módulo de Relatórios** - Gera relatórios executivos
